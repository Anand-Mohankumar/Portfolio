Change owner of a file or directory
This command helps to change ownership of a file or directory in you system

-R can be used along with this command to apply the changes to all subdirectories and files inside the specified directory

Pro Tip : Instead of running chown and chgrp commands back to back, you can use : chown username:grpname filename/directory name.

The OS will understand the part after the : to be group name

-R can be used along with this command to apply the changes to all subdirectories and files inside the specified directory

Processes and Jobs

Application / Services = Programs that run in the computer
Script = Something that is written in a file and packaged it in a way that it will execute. eg : adduser , cd, pwd
Process = When you run an application, it generates processes with process ids
Daemon = Process that continuously running in the background until it is interrupted.
Thread = Every process could have multiple threads associated to it for different tasks for example : For every computer that tries to connects to your Linux machine, it generates a seperate thread for each.

Shell Scripting

What is Shell Script?

A Shell script is an executable file containing multiple shell commands that are executed sequentially. The file contains :
  • Shell ( #!/bin/bash ) ; Note : Shell Scripts should always start with the shell command ie #!/bin/bash ( the /bin/bash can change based on the type of script you are running for example bash, powershell etc )
  • Comments ( #comments )
  • Commands ( echo, cp, grep etc. )
  • Statements (if , while , fore etc. )

Shell script should have executable permissions ( e.g. -rwx r-x r-x ).
Shell script has to be called from absolute/complete path ( e.g. /home/userdir/script.bash )
If called from current location then ./script.bash also works.

Shell History

Very effective for system admins to troubleshoot

Shows Who did what??

Command : $history
Pro Tip : The history command output also has numbers associated with each command execution which can be used to run that command again.
For eg, given below is an example output of history command :

1  cd /
2  pwd
3  ls -l
4  whoami
5  pwd
6  shutdown -r +5 "Fatal Error, Losing Power, Goodbye idiot"

Let's say you wanted to run the 6th command on the list above. But you want to save some time in typing the whole thing. How do you do that?
Here is how :
$ !6
By executing bang ( ! ) followed by the number of the command, the system will re run the same command associated with the number you specified ( 6 in this case ).

Bonus Pro tip for the previous Pro tip : If you remember parts of a long command you executed before , run history command by piping it through grep and search for the keyword or command you remember.

Network Files and Commands

Should have :
  • Interface Detection
  • Assigning an IP address
  • Interface configuration files
    • /etc/nsswitch.conf   =   Tells the system where it should resolve its hostname to IP
    • /etc/hosts  =  Where you define you system IP address and system host name
    • /etc/sysconfig/network  =  Where you specify hostname
    • /etc/sysconfig/network-scripts/ifcfg-nic  =  Network Interface Card Configurations
    • /etc/resolv.conf  =  Specifies DNS Server

Network Commands :

ifconfig
Gives Information about Network Intefaces that are active on your system.
The command displays information such as :
  • Private IP address
  • Subnet Mask
  • Broadcast IP
  • etc.

ping
Transfers sample packets to a specified domain/IP to verify if it is active and capable of communication
$ping google.com

Will display the data of packets transferred to google.com and as an end result shows the success rate as in how many of the packets sent is successfully recieved at google.com and what percentage of packets failed to reach the destination.
ifup or ifdown
Turn on or off an interface
$ifup nicname
netstat
Print network connections, routing tables, interface statistics etc.
$netstat
$netstat -rnv
Displays the most essential info only ( like IP, Gateway,Netmask,Flags,Interface etc )
tcpdump
Packet analysis/sniffing tool
$tcpdump -i enp0s3
Captures all packets entering and leaving 'enp0s3' interface.

Linux Package Management


Applications are installed by package managers and here are a few package managers :

  • dpkg - Low level package manager ( kinda stupid ).
  • apt - advanced packaging tool
Example Install discord on Linux :

  1. Go to https://discord.com/download
  3. cd to /home/username/Downloads and use ls command to see the file that is downloaded
    The OS we are using is Debian based. So the package extension .deb is an indication of that. This is similar to .exe in windows or .dmg in mac.
  4. To install using dpkg manager use the command $ sudo dpkg -i discord-0.0.19.deb

Flaw with DPKG :
Requires us manually installing the dependencies that the application need to function.
Which brings us to apt

Advanced Packaging Tool
General use : $ sudo apt install discord
APT is a high level package manager
APT uses repositories ( storage location of softwares that we might want to use ) to fetch packages from the web when we use the command.
For the above discord example, the apt will look in repository to find 'libatomic1', 'libconf-2-4' and 'libc++1' if we used apt instead of dpkg.

Doesnt require .deb file to install an application.

The apt repository when updated needs to provide the up-to-date list of packages to the system. Hence for this purpose use : $ sudo apt update which will update the list.

Git and Github
Github has reporsitories that contains scripts that can be used for various purposes. And In order to use Github in Linux we need GIT.

How to get files from git repositories.

First Install git if you haven't already  : $sudo apt install git

Download the files from the repository : 

Go to a Browser, Search Turbolist3r and visit the first link ( from github ). Now Copy the url and use it in the command below
$ git clone https://github.com/fleetcaptain/Turbolist3r

This will clone the content  in that link to you current working directory ( May it be Desktop, Downloads, Home or watever ).

Now lets try this tool out. Its a pythonbased script that comes with some requirements ( dependables )

Let's cd into the cloned directory and use ls to list the content

The requirements,txt file you see here contains what all packages this tool depends on. Hence we have to install them too. But thanks to PIP (python's package manager) its easy.

First make sure you have pip installed. If you don't have it :  $sudo apt install pip
Now that pip is ready do the following command : $ pip3 install -r requirements.txt ( This basically means : pip3 = we are using python3 ; -r = read ; requirements.txt = Duh!! It has the requirements obiviously ).

This basically tells the pip to install whatever is written in the requirements.txt file.

Now to run the script

For help on how to use the tool : $ python3 turbolist3r.py -h
To run the domain scan : $ python3 turbolist3r.py -d google.com
This lists all the subdomains of google.com
