# Anand Mohankumar - Interactive OS-Themed Portfolio

Welcome to the repository for my interactive personal portfolio! This project is designed as a fully functional, web-based operating system simulation that showcases my professional background, skills, and projects in Security Operations and Compliance. 

## 🌐 Live Demo
**[cyberamo.work](https://cyberamo.work)**

## ✨ Key Features
* **OS Desktop Experience:** A simulated desktop environment complete with a boot sequence, top navigation bar, and an animated MacBook-style dock.
* **Glassmorphism UI:** Draggable, maximizable, and minimizable windows built with frosted glass effects and dynamic drop shadows.
* **Custom WebGL Background:** A highly optimized, abstract fluid/heatmap shader running in the background via WebGL.
* **Interactive Terminal:** A fully functional command-line interface simulation. Try typing `whoami`, `help`, or `clear`.
* **Resource & Infographic Gallery:** A structured knowledgebase hosting my lecture notes, InfoSec resources, AI workflows, and custom infographics.
* **Fully Responsive:** Adapts seamlessly from a sprawling desktop view to a stacked, touch-friendly mobile layout.

## 📂 Portfolio Sections
* **Home:** Professional bio detailing my experience as a Revenue Operations Analyst and Security Professional at EQS Group, along with social links.
* **Projects:** Quick links to my professional work, certifications, and my curated 'InfoSec Daily' feed.
* **Skills:** Categorized breakdown of my industry knowledge (SIEM, TPRM, Vulnerability Management), tools (Wazuh, Splunk, AWS), and interests (CTF, OSINT).
* **Terminal:** A simulated CLI to interact with my profile programmatically.
* **Resources & Knowledgebase:** Hub for:
  * Labs, Research & CTF writeups
  * AI & Automation workflows (N8N, prompt engineering)
  * Custom Infographics (AI Roadmaps, RAG explained, etc.)

## 🛠️ Technologies Used
* **HTML5:** Semantic structure and custom data attributes.
* **CSS3:** Advanced animations, CSS Grid/Flexbox, `backdrop-filter` for glass effects, and complex media queries for responsive design.
* **Vanilla JavaScript:** DOM manipulation, window dragging logic, z-index management, and terminal command parsing without any external UI frameworks.
* **WebGL & GLSL:** Custom fragment and vertex shaders to generate the large-scale abstract liquid background.

## 🚀 How to Run Locally
Since this project is built entirely with vanilla web technologies, no build tools or package managers are required.
1. Clone the repository:
   ```bash
   git clone [https://github.com/Anand-Mohankumar/Portfolio.git](https://github.com/Anand-Mohankumar/Portfolio.git)
   ```
2. Navigate to the directory:
   ```bash
   cd Portfolio
   ```
3. Open `index.html` in your favorite modern web browser.
